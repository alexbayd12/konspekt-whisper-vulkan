# whisper.cpp + Vulkan для Windows x64

Автоматическая сборка [whisper.cpp](https://github.com/ggml-org/whisper.cpp) из официального
исходного кода с ускорением **Vulkan** — для распознавания речи на видеокартах **AMD** и Intel
(и NVIDIA) в Windows. Официальные релизы whisper.cpp такой сборки для Windows не содержат.

Используется как дополнение программы «Конспект лекций»: программа сама находит видеокарту AMD,
предлагает скачать архив из [релизов](../../releases), проверяет контрольную сумму SHA-256.

Сборка — `.github/workflows/build.yml` (запуск вручную, можно выбрать версию whisper.cpp).
Здесь нет собственного кода: только сценарий сборки. Лицензия whisper.cpp — MIT (`LICENSE-whisper.cpp.txt` в архиве).
